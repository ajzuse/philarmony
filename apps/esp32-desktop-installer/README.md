# Philarmony ESP32 Desktop Installer

Flutter desktop app (FVM **3.44.0**) for guided USB flash of Philarmony firmware.

```bash
# from repo root
make run                 # or: make run-macos
make test-flutter
make create-platforms    # already done if macos/windows/linux exist
```

See `packaging/README.md` and `specs/002-esp32-desktop-installer/quickstart.md`.
